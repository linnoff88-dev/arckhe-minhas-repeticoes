Em resumo

Quem trabalha com agentes de IA pede as mesmas coisas muitas vezes e não percebe, porque cada vez parece a primeira. Minhas repetições é um kit gratuito que lê o histórico do Claude Code e do Codex guardado no seu computador e mostra o que você mais repete. Para cada repetição ele diz se vale virar um atalho (um texto curto que você cola com um gatilho), uma skill (um procedimento com passos que o agente segue) ou se é só uma resposta como "sim". Para usar basta ter Python 3: não chama API e nada sai da sua máquina.

Atalho, skill ou resposta

Nem toda repetição pede a mesma solução

O kit separa cada grupo de pedidos repetidos nestes quatro tipos (mais dois de apoio: link colado e comando que você já usa). A diferença está no tamanho, nos passos e no que o pedido quer (como usar ↓).

⌨️ Atalho

Pedido curto e sempre igual, como "publique no portal". Você digita um gatilho curto (o kit sugere ;portal-publica) e o texto aparece. O kit já entrega a lista pronta.

🧩 Skill

Pedido longo, com passos ("crie o repo, rode os testes, faça o guia, publique"). Vira um procedimento que o agente segue sempre igual. O kit entrega o rascunho.

💬 Resposta

"sim", "continue", "pode fazer". Não vale atalho. Se aparece demais, o agente está perguntando demais.

📟 Checagem

"qual a situação?" repetido 68 vezes não pede atalho: pede um aviso no fim, uma barra de status ou um painel. O kit marca esses grupos e não gera atalho para eles.

Dicas

O que fazer com o que você repete

As 12 dicas completas estão no kit (DICAS.md). As que mais mudam o dia a dia:

1

Pensar no grande, executar no rápido

Abra com o modelo maior (no Claude, o Fable) quando ainda não sabe o caminho. Plano claro, troque para o mais rápido (o Opus) e execute.

2

Baixe o esforço, não escreva "não pense demais"

Se o modelo pensa demais para a tarefa, quem resolve é o nível de esforço (uma configuração de quanto ele pensa), não uma frase no pedido.

3

Quem escreveu não revisa

Mudança média ou grande vai para outro agente revisar, de preferência de outra empresa (o Codex revisando o que o Claude fez, por exemplo).

4

Rotina vira vigia barato

Um script confere primeiro; a IA só entra quando ele acha um problema. Rodada sem problema não gasta nada.

5

Tarefa longa avisa no fim

Critério de pronto escrito e "Terminei: …" no final tiram o "qual a situação?" do seu dia.

6

Meça de novo em 30 dias

O número que importa é a sua repetição caindo depois dos atalhos e das skills.

Parte técnica

O kit: para quem quer medir o próprio histórico

Daqui para baixo é a parte técnica: instalar, rodar e ler o relatório. Você não precisa desta parte para entender o que está acima.

O que é

Um arquivo, sem dependências

repeticoes.py lê os logs que o Claude Code e o Codex já guardam no seu computador e escreve um relatório.

🔒 Só local

Biblioteca padrão do Python. Não chama API, não instala nada, não manda nada para fora.

🧑 Só o que você digitou

Robôs, vigias, notificações e subagentes ficam fora da conta (e aparecem à parte). Sessão retomada não conta duas vezes.

✍️ Aceita erro de digitação

"qual sistuacao" e "qual a situação?" caem no mesmo grupo; "publica", "publique" e "publicou" também.

Como funciona

Do log ao atalho

Cada etapa roda em segundos; 11 mil sessões levaram cerca de 1 minuto.

Lê ~/.claude/projects e ~/.codex/sessions→ Separa você dos robôs→ Junta pedidos parecidos→ Classifica: atalho · skill · checagem · resposta (+ link, comando)→ Mede modelo, esforço, limite, turno longo→ relatorio.html + atalhos + rascunhos de skill
Pré-requisitos

O que precisa

Nada além disto.

Python 3.9+

Já vem no Linux. No Mac pode pedir as ferramentas de linha de comando; no Windows use py no lugar de python3.

python3 --version

Histórico do Claude Code ou do Codex

Fica em ~/.claude/projects e ~/.codex/sessions. Basta ter usado.

ls ~/.claude/projects | head

Espanso (opcional)

Expansor de texto livre para usar os atalhos gerados. Serve qualquer outro.

# espanso.org
Guia de uso · passo a passo

Do zero ao seu relatório

Comandos reais do kit.

1

Baixe o kit

Um repositório público, um arquivo principal.

git clone https://github.com/inematds/minhas-repeticoes
cd minhas-repeticoes
2

Confira que roda

15 testes com um histórico inventado (nenhum dado seu).

python3 -m unittest discover -s testes   # Ran 15 tests ... OK
3

Leia o seu histórico

Padrão: últimos 30 dias, pastas padrão do Claude Code e do Codex.

python3 repeticoes.py
# 2287 pedidos seus · 12.6% em repetição · 6 atalhos · 3 skills · 73s → relatorio/relatorio.html
python3 repeticoes.py --dias 7 --saida semana   # outra janela
python3 repeticoes.py --sem-codex               # só Claude Code
4

Abra o relatório

Gráficos de repetição, grupos, modelo, esforço, limite e turnos longos. Abre no navegador, sem internet.

xdg-open relatorio/relatorio.html   # no Mac: open
5

Ligue os atalhos

Cada pedido curto repetido vira um gatilho (checagens ficam de fora). Revise antes de copiar. No Mac a pasta é ~/Library/Application Support/espanso/match/.

cat relatorio/atalhos-espanso.yml
cp relatorio/atalhos-espanso.yml ~/.config/espanso/match/repeticoes.yml
6

Transforme em skill o que tem passos

Cada rascunho traz 3 exemplos de como você pediu. Escreva os passos, troque o que muda por argumento e mova para as suas skills. Ou instale a skill do kit e peça ao agente para fazer isso com você.

ls relatorio/skills-rascunho/
mkdir -p ~/.claude/skills
cp -r skill/minhas-repeticoes ~/.claude/skills/
cp repeticoes.py DICAS.md ~/.claude/skills/minhas-repeticoes/   # depois, no agente: "o que eu repito?"
7

Meça de novo em 30 dias

Compare os dois numeros.json: é o único arquivo sem nenhum texto seu.

python3 repeticoes.py --saida relatorio-mes2
